# UI assets

`ChronosLiveLogo.png` uses the supplied official PNG artwork. Its embedded dark background was removed and the transparent edges were trimmed for legible display; the original source at the repository root is unchanged.

The three JPEGs are decorative crops from the supplied `REFERENCE.png`. They provide default service imagery in the reference's photographic style. A service's real uploaded `coverImageUrl` takes precedence. Images do not supply service names, locations, dates, prices, capacities or other application data.
