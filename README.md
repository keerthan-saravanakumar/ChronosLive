# ChronosLive

Real-time scheduling with fair waitlists and concurrency-safe booking.

Implementation is in progress. See [docs/PROGRESS.md](docs/PROGRESS.md) for verified status and [docs/DECISIONS.md](docs/DECISIONS.md) for the approved design.

## Local Setup

Node.js 22.12+ (Node 24 LTS recommended). Run `npm install`, then `npm run dev:server` and `npm run dev:client` in separate terminals. Configuration examples are in each workspace.
